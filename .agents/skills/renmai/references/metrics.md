# 指标口径

所有指标都从单聊消息计算；群聊只用于“共同群 / 桥接”这一层，不进入关系强度。

## 1. 会话段

相邻消息间隔 **> 6 小时** 切分为新的一段。用于区分“持续对话”和“隔几天回一句”。

- `sessions`：总段数
- `sessions_mine` / `sessions_theirs`：谁先开口

## 2. 回复时长

同一会话段内，角色切换的间隔；超过 24 小时的切换不计入（那是重新开始，不是回复）。

- `reply_me_median`：我回对方的中位数
- `reply_them_median`：对方回我的中位数
- 只保留中位数，避免极端值污染

## 3. 关系强度（0–100）

```
强度 = 0.28 × 频率
     + 0.30 × 近因
     + 0.18 × 双向均衡
     + 0.12 × 持续度
     + 0.12 × 回复速度
```

| 分项 | 公式 | 说明 |
|---|---|---|
| 频率 | `min(1, log10(消息数) / log10(30000))` | 3 万条封顶 |
| 近因 | `exp(-沉默天数 / 120)` | 半衰期约 83 天 |
| 双向均衡 | `1 - |我-对方| / (我+对方)` | 1 = 完全对等 |
| 持续度 | `min(1, 活跃月数 / 12)` | 跨年关系加分 |
| 回复速度 | `max(0, 1 - 回复中位数 / 7200)` | 2 小时封顶 |

分层阈值：

- `≥ 82` 核心圈
- `62–82` 活跃层
- 其余：`> 365 天` 失联层 / `90–365 天` 沉睡层 / 其他外围层

## 4. 关系债

`last_is_theirs == true` 且 `沉默天数 ≥ 3`。
优先级 = `强度 × min(沉默天数/30, 3)`。

**解释**：对方最后说话、你还没回。强度越高、拖得越久，损失越大。

## 5. 沉睡资产

`历史消息 ≥ 100` 且 `90 ≤ 沉默天数 ≤ 730`。
这类关系的“复活成本”最低：有过真实往来，只是断了。

## 6. 桥接分

一个人能在共同群里直接连接到的、**你也聊过**的人数。

```
bridge_score(u) = |{ v ∈ chat_users : ∃g, u∈g ∧ v∈g }|
```

它衡量“这个人能给你介绍多少人”，不是他自己有多少群。

## 7. 中介中心性

在“人与人共同群”的加权无向图上，用 Brandes 算法计算（未加权最短路）。
值越高，越像“路由器”。规模在 2,000 人以内可在纯 Python 中秒级完成。

## 8. 结构洞约束（Burt's constraint）

```
constraint(u) = Σ_j ( p_uj + Σ_k p_uk · p_kj )²
```

`p` 是边上权重的归一化比例。**值越低，越处在结构洞位置**（能连接不同圈子）。

## 9. 社区

标签传播（label propagation），确定性顺序，20 轮内收敛。只用于分组展示，不做因果解释。

## 10. 状态标签

`tag` 是给报告用的短标签，规则优先级：

1. `>365 天` → 已失联
2. `>90 天` → 已冷却
3. `≤10 条` → 一次接触
4. 我发言 ≥65% → 你单方面输出
5. 对方发起 ≥70% → 对方在主动
6. 共同群 ≥5 → 跨群节点
7. 我发言 ≤40% → 对方主导
8. 强度 ≥62 → 稳定双向
9. 其他 → 低频维持

## 11. 盲区

- 线下关系在聊天记录里不可见（微信 6 条 ≠ 关系浅）。
- 群聊里的互动不计入强度，会低估“群里很熟”的人。
- 语音、图片、文件只有占位符，语义分析会失真。
- 组织结构（谁是谁的领导）无法从聊天里可靠推断。
