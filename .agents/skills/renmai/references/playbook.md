# 行动手册

报告只是诊断，行动才是产品。这一页定义“看完报告之后做什么”。

## 1. 四象限

| | 资源量级低 | 资源量级高 |
|---|---|---|
| **关系强** | 陪伴 / 情感底盘 | **杠杆**：优先投入 |
| **关系弱** | 噪音 | **隐形资产**：最该补 |

- **资源量级**只能由用户提供（`labels.json` 的 `tier`）。
- **关系强度**由指标计算。
- 不要用“消息多”代替“关系强”，也不要用“头衔大”代替“有资源”。

## 2. 关系债怎么还

优先级：强度高 + 拖得久。

开场三选一，**不要**用“在吗 / 最近怎么样”：

1. **具体近况**：“上次你说 X，我这边刚好碰到一个类似的情况。”
2. **结果回传**：“你之前提的 Y，我试了，结论是 Z。”
3. **明确请求**：“有件事想请你帮我看一眼，10 分钟就够。”

原则：一条消息里必须有一个**只有你们两个人知道的细节**。

## 3. 沉睡资产怎么复活

- 选 `历史 ≥ 100 条 + 双向均衡` 的人。
- 切口用共同经历，不要用节日祝福。
- 目标不是“恢复高频”，是“确认这条线还在”。

## 4. 桥接者怎么用

- 桥接分 ≥ 2、但私聊 < 10 条的人，是“未开采的引荐人”。
- 破冰理由天然存在：“在 X 群看到你提到 Y”。
- 不要一上来求引荐；先建立一次真实对话，第二次再提。

## 5. 资源层怎么维护

对高量级的人，**不要“维护关系”，要“交付东西”**：

| 关系类型 | 你要给的 | 你要的 |
|---|---|---|
| 投资人 | 一页纸 + 可验证的数据 | 判断 + 一个引荐 |
| 产业方 | 一个可验收的小试点 | 场景 + 订单 |
| 政府/平台 | 落地清单（就业、税收、时间表） | 场地 + 政策 + 背书 |
| 学术 | 一个真问题 + 进展 | 背书 + 联合课题 |

## 6. 每周复盘（10 分钟）

1. 打开 `network_weekly.py` 的输出，挑 3 条。
2. 每条只做一件事：发一条有具体内容的消息。
3. 下周看这三条有没有回音；没有就换人，不要追。

## 7. 不要做的事

- 不要群发问候。
- 不要给关系打分后到处说。
- 不要把别人的资源当成自己的战绩。
- 不要用这份数据去“研究”某个人。
